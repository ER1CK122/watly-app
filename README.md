# Watly 💧

Watly é uma aplicação **open-source** desenvolvida em **Next.js** e **React** para ajudar você a monitorar sua ingestão diária de água, manter hábitos saudáveis e atingir metas personalizadas de hidratação.  

O objetivo é tornar o processo simples, intuitivo e motivador, com recursos de gamificação, streaks e visualização de progresso.

---

## 🚀 Funcionalidades

- ✅ Registro rápido da quantidade de água ingerida
- ✅ Visualização do total diário
- ✅ Definição de metas personalizadas
- ✅ Contagem regressiva para o fim do dia
- ✅ Gamificação (streaks, conquistas futuras)
- ✅ Interface simples e responsiva

## 🛠️ Instalação local

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/watly-app.git

# Entre na pasta
cd watly-app

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
Acesse http://localhost:3000 para ver o app rodando localmente.
```
